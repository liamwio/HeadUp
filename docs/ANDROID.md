# HeadUp Android 1.1.12-apponly 应用内保存分支

当前版本只使用“用户”概念。家庭账号、家庭同步、限时分享、拍摄交接和原生家庭服务器入口已关闭；旧数据不会因此被删除。本说明取代 1.0.0 的家庭服务器使用说明。

## 安装与开始

安装包：`releases/android/HeadUp-1.1.12-apponly-debug.apk`。包名 `com.headup.growth`，versionCode 14，最低 Android 7.0（API 24），目标 API 36；要求 Android System WebView 119 或更新版本。与本项目 1.0.0 使用相同调试签名，可以覆盖更新。

首次进入直接创建档案，仅显示名称与出生年份选择。年份可暂不填写；无需角色、用途、默认侧面或原第三步勾选。创建后进入拍摄，界面分为 **正面 → 侧面**。侧面先显示左侧虚线轮廓，左侧照片完成侧面测量后自动切到右侧；相机拍摄会自动打开右侧取景框，选图则进入右侧选择页面。检测失败时保留照片供核对或重拍。允许暂时跳过，稍后补拍；完整记录要求三张照片。左右侧分别保存照片和分析结果，可在详情与时间对照中查看。

模型内置于 APK，不需要首次联网下载。数据保存在应用私有存储中，与手机浏览器及电脑浏览器分开。卸载、清除应用数据或换机前，请导出加密备份。旧版备份仍可导入；旧有单侧记录无需补齐另一侧才能查看。

拍摄页显示“名称的本次记录”。相机拍摄自动记录日期；导入照片优先读取 DateTimeOriginal，其次读取 CreateDate，保留照片原始日历日期。没有元数据、日期无效或多张日期不一致时留空并提示手动填写，不使用导入时间或文件修改时间冒充拍摄时间。已删除“这些照片是今天拍的”按钮。

记录用途为“面部生长记录”或“其他”；选择其他可填写自定义用途，记录、照片和用途一起保存，在时间线、详情、导出及备份恢复中保留。用途是用户的记录分类，不增加对骨骼结构的分析能力。

## 本分支存储规则

- Git 分支：app-only-photos；目录：D:/AICodex/HeadUp-AppOnly。原项目 D:/AICodex/HeadUp 保持不变。
- 照片随“保存到档案”写入原有应用内数据库，原图、分析图及测量历史结构不变。不自动写入 Pictures/HeadUp、系统相册或其他共享文件目录。
- 停用拍后复制、提交后复制、启动补存和前台重试；不处理旧版目录待保存队列。原生目录写入接口拒绝旧页面调用，不初始化目录控制器。
- 移除手机照片目录、补存及相关删除提示。用户主动导出加密备份/资料的功能仍保留，不属于自动保存。
- 已经写到共享目录的旧照片不会被删除；应用内历史也不迁移或清空。未提交的拍摄页面仍遵循原有离开确认，不自动建立时间线记录。
- 保持原包名 com.headup.growth 和签名，APK 可覆盖升级已有安装并使用其原数据库。它不是可以并排安装的第二个应用。本轮仅构建，不替换当前手机版本。
- 清除应用数据/卸载会影响应用内照片，请使用已有主动备份功能。
- 本地开发复用原项目 node_modules 和 .android-tools 的目录联接；源代码和 Android 工程、构建输出独立。未复制私人照片、运行数据和密钥配置。

## 1.1.11 原版历史（目录保存功能在本分支关闭）

- 修正原生桥接只接收 Long、遗漏 JSON Integer 文件大小的问题，避免正常照片被误判为空或超限。

- 相机选定一张照片后立即自动保存原图，不再依赖“保存到档案”，新记录和补拍都适用。重拍前已选定的照片也保留在手机目录；未选中的连拍帧不保存。
- 自动保存不依赖检测成功。照片先写入独立 IndexedDB 待保存队列，目录写入失败后在下次启动或回到应用时重试；成功后清除队列中的临时副本。卸载或清除应用数据会移除尚未写入目录的待保存照片。
- 启动/回到应用时自动补存已有本机档案照片，已完成的记录不会反复处理；保留手动补存入口以便用户恢复自行删除的目录副本。
- 相机原图使用拍摄日期、视角和内容校验码标识，之后提交记录会复用同一原图目标；扶正分析图仍在保存档案时另存。
- 界面布局及测量算法不变。自动另存图片不等同于自动创建时间线记录，记录仍需核对后保存。

## 1.1.9 已有功能（自动保存触发方式以 1.1.11 为准）

- 拍摄底部恢复“相册 / 拍摄 / 切换镜头”，左右提示卡和大取景保留；其他选项仍在“更多”。
- 保存记录后，按档案另存照片目录副本。Android 10+：`内部存储/Pictures/HeadUp/档案名称_完整档案编号/`；Android 7–9：应用专属外部照片目录，具体路径在档案页显示。
- 文件名包含拍摄日期、记录编号、正面/左侧/右侧、原图/分析图及校验码。保存的是应用中保留的照片字节，不保存落选连拍帧；有扶正前原图时同时保存原图和分析图。
- 档案页增加“手机照片目录”及“补存当前档案照片”，历史补存包含各保存版本；校验一致的副本跳过。自动保存中断时保留待处理编号，下次打开应用重试，不自动批量补存所有旧档案。
- 目录写入失败不影响已经提交的应用记录。Android 10+文件完成并校验后才发布到媒体库；旧系统先写临时文件再改名。
- 目录是独立照片副本，不是完整档案备份。应用内删除记录/档案不删除目录副本；档案改名不搬动既有目录。更正日期也不改名已有副本，补存按当前日期另存。
- Android 10+共享目录中的照片卸载后通常仍保留；Android 7–9的应用专属目录会随卸载删除。没有增加读取全相册或管理所有文件的权限。

## 1.1.8 已有功能

- 实时提示分列取景区两侧：左侧为距离、位置、入镜；右侧为角度、光线、清晰度。
- 正常、待调整和待检测使用不同颜色与文字/图标表达，重要的多人、遮挡和模型未就绪提示仍保留。
- 相册、切换镜头与全部拍摄选项统一进入“更多”，底部只保留拍摄按钮。
- 设置展开时收起两侧提示卡并暂停自动拍摄；切换镜头后自动返回取景。

## 1.1.7 已有功能

- 拍摄页改为取景优先，默认下方仅一条提示及相册/拍摄/切换按钮。
- 六项检查、自动拍摄、语音、连拍、震动及构图参考收进右上角“更多”，展开不压缩取景区。
- 设置展开时暂停自动拍摄；收起后重新判断稳定条件，避免操作选项时自动拍下。
- 精简提示文字，保留侧面角度估计不确定性；画面与取景线仍保持等比例对齐。

## 1.1.6 已有功能

- 新默认记录周期为30天，保留一周/两周/自定义；已有计划不改写，短间隔趋势增加提示。
- 用途显示为“面部生长记录”，旧用途原值仍保存在备份中。
- 结果使用正面/左侧/右侧标签；点名默认隐藏，放大后显示；出生年默认近25年，保留旧档案年份。
- 新增可选身高手动记录、来源、独立曲线及时间线展示，支持编辑/删除和备份恢复。
- 新增一页A4 PDF资料导出：主动选择1至3次记录，包含照片、保存读数和拍摄条件，可选不含名称/照片。
- 收紧趋势和侧面角度文案；不把照片读数差异直接称为真实生长。
- 多帧中位数仍为离线研究原型，未打包或启用；毫米换算、真实变化标签和跨期轮廓叠图未启用。

## 1.1.5 已有功能

- 侧面检测不再依赖正面网格模型；辅助颈线异常不丢弃已完成的面部测量。
- 显示侧面测量失败阶段及模型估计角度；修正姿态拒绝时误显示“0张人脸”的问题。
- 侧面失败后停留核对页，可重新检测原照片；持续角度提示引导用户核对手机机位，避免反复扭头。
- 短连拍选帧后复核实际保留照片；未通过时显示照片，支持重拍或保留原图。
- 侧面虚线后脑勺改为更饱满圆弧，左、右侧同步。

## 1.1.4 已有功能

- 修正侧面点位分组，分别绘制眉、鼻、上下唇和下颌；拦截异常输出。
- 新测量遵循关键点 → 测量线 → 数值，点击指标可以核对对应点线与计算关系；不再用直接预测数值代替侧面点位几何。
- 至少3次照片记录后自动生成趋势报告；保存后自动进入报告，后续记录自动更新；移除手动选择两次对照。
- 计算来源、公式、视角或拍摄条件不一致时不强行计算变化；旧记录原值保留。

## 文件、相机和提醒

- 开始拍摄时请求相机权限，也可从相册选图。
- 加密备份、PDF资料、HTML 摘要、日历及图片导出使用系统文件保存器，由用户选择位置；单文件上限 64MB，完整档案可使用分卷备份。
- 返回键优先关闭弹层；未保存内容保留确认流程。
- 提醒沿用页面可见时提示及导出日历方式，尚未加入 Android 原生后台定时通知。
- 当前 Android 版本为本机模式，不能配置家庭服务器或通过该入口使用云端 AI。独立右侧报告也尚未纳入现有阶段 AI 输入。

## 构建与验证

双击根目录 `构建Android.cmd`，或运行 `pnpm android:build`。

构建流程：TypeScript 检查 → Android Vite 资源 → Capacitor 同步 → 原生编译、JUnit、Lint → 复制 APK 并生成 SHA-256 与 build-info.json。

本机 JDK 21、Android SDK 36、Build Tools 36.0.0 位于 `.android-tools`，SDK 许可已获用户授权接受。其他机器可安装对应工具并设置 JAVA_HOME、ANDROID_HOME，依赖使用 pnpm 锁文件。

当前分支代码通过 729 项测试，并在浏览器隔离环境验证拍后复核、重拍恢复、保留照片、摄像头释放及手机布局。Android 构建、签名及内容检查见 `releases/android/VALIDATION-1.1.12-apponly.md`。这是调试签名测试包，尚未完成 Android 真机相机、系统选图/保存与返回键端到端验收。

24张研究照片的视觉复核仍发现部分侧面眉部、下颌定位偏差；本版不宣称儿童定位或跨期变化精度已经验证。详见 `data/validation/llm-drawing-review-2026-09-22/REPORT.md`。

用户提供的7张照片复现中，仍有3张侧面被姿态检查拦截；独立诊断也发现部分点位偏差。本版打包流程改进，不表示侧面定位准确性问题已经解决。私人测试照片与诊断结果未打包。

新增身高采用HEADUP-EVENT-2结构；包含身高的新备份应使用1.1.6或更新版本恢复，旧版不能识别该结构时会拒绝导入。旧档案和旧备份仍可使用。
