# Project workflow preferences

- For future UI changes, first show the user a before-and-after visual comparison, then automatically build, sync, and package the updated Android version without asking again whether to build it. Capture the pre-change interface before editing when available, and use matching views and viewport sizes for the comparison. Preserve previous APKs and create a new version for each Android update. This replaces the former web-only default (user instruction, 2026-10-12).
- Validate changed web behavior and build the web frontend so the running local service can serve it.

- Measurement provenance: identify landmarks, construct lines from those same saved points, then calculate displayed measurements from that construction. Do not substitute direct model-predicted numbers for the displayed geometry. Preserve old saved results and prevent comparisons across incompatible measurement sources.
